# Интернет-магазин на Django

Проект интернет-магазина, разработанный с использованием Django и Bootstrap.

## Функциональность

- Главная страница с товарами
- Страница контактов с формой обратной связи
- Адаптивный дизайн на Bootstrap
- Обработка форм с выводом сообщений об успехе
